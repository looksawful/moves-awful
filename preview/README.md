# Movesawful · Storybook

Истории используют настоящие реализации Canvas Arc/Spiral и управление DPR.

Истории: Arc, Spiral, повышенный DPR, экономный DPR; освобождение ресурсов при уходе со страницы.

Запуск в каталоге preview: `npm ci`, `npm run storybook`. Сборка: `npm run storybook:build`.

Проверено 2026-11-07 на Titan (Node 24): `npm run storybook:build` → OK.

GitBook (не опубликован): https://app.gitbook.com/o/vNK58vV2S63vxervMh3G/sites/site_s5EHT

Ограничение: сборка не подтверждает соответствие нативному UI. Деплой и runtime не меняются.
