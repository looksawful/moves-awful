# MOVES AWFUL — Arc / Spiral: дизайн, реализация, продукт

**Дата спецификации:** 2026-11-20  
**Статус:** спецификационный макет, **не** эталонная запись и **не** готовый AE-шаблон. **Объём уточнён 21.11.2026: только After Effects, сборка скриптами JSX.**  
**Задача / единая точка учёта:** [GitHub #47](https://github.com/looksawful/moves-awful/issues/47).  
**Исходный код:** [`canvas-animations/arc.ts`](../../canvas-animations/arc.ts) и [`canvas-animations/spiral.ts`](../../canvas-animations/spiral.ts).  
**Ревизия, с которой сверялась спецификация:** `1162f506cfb3049b215adfe416994783269918c0` (`master` на момент чтения). Это **не** подтверждённый SHA опубликованного превью.

**Макеты:** [интерактивный motion-board](arc-spiral-motion-board.html) и [статическая векторная доска](arc-spiral-overview.svg). Открываются отдельно от runtime-библиотеки. Плейсхолдеры на макетах **не являются оригинальными обложками и не служат pixel-perfect эталоном**. Их задача — объяснить геометрию, фазы, слои и заменяемый контент.

## 1. Продукт / Product

**Зачем:** выпускать визуально совпадающие, пригодные для повторного использования анимированные композиции MovesAwful в After Effects с помощью JSX-скриптов, меняя изображения и надписи без переработки движения. Потенциальные места применения: обложки, промо, кейсы, контент для сайта и клиента. Это предположения о применении, а не подтверждённые пользовательские метрики.

**Для кого:** дизайнеру нужна читаемая композиция и управляемый контент; motion-дизайнеру / разработчику — предсказуемые слои и проверяемая геометрия; продукту — минимальный критерий запуска и измеримая приёмка.

**MVP / единица поставки:** сначала **Arc**: один JSX-скрипт сборки, один редактируемый `.aep`, одно короткое превью, инструкция по замене контента и QA-сравнение. **Spiral** начинается после Gate Arc. Отдельный редактор, генератор шаблонов, MOGRT, новый движок, дополнительный сайт и изменения runtime не входят в MVP.

**Приёмочные вопросы:**
1. Сравнили одинаковые фазы, размер кадра, исходные изображения/тексты и шрифт между оригиналом и AE?
2. Движение/масштаб/обтравка/перекрытия/затухание/типографика достаточно близки? Несовпадения перечислены, не скрыты.
3. Можно заменить картинку и строку в Arc, снова открыть `.aep`, перерендерить без отсутствующих медиа?
4. JSX-скрипт воспроизводимо создаёт `.aep` с редактируемыми медиа и текстом? Есть исходники, превью, source SHA и короткий тест-лог на Titan?

**Решение по объёму:** выполнить Arc; при положительной проверке использовать освоенный способ для Spiral. Не обещать pixel-perfect заранее.

## 2. Дизайнер / Designer

### Что смотреть в макетах

- `arc-spiral-motion-board.html`: интерактивные Arc / Spiral, фаза 0..1, размеры desktop/mobile, тёмный/светлый фон хоста, два зафиксированных кадра Arc. Фон, сетка и панель управления — **обрамление макета**, не функциональность библиотеки.
- `arc-spiral-overview.svg`: статическая монтажная доска для быстрой передачи композиции, форматов, состояний и ролей.
- **Важно:** рисунки обложек в обоих файлах синтетические. Их цвета и содержание нельзя принимать как эталон исходного медиапака.

### Arc — структура

1. Прозрачный Canvas внутри хостового блока. Размер композиции зависит от фактической ширины и высоты блока; нет отдельной mobile-версии алгоритма.
2. Центр окружности `x = width / 2`, `y = height` (на нижней кромке). `radius = min(width, height) × 0.7`.
3. **Десять слотов** по полному кругу; во видимом кадре обычно остаётся лишь верхняя часть дуги. Не путать число слотов и число исходных обложек: по циклу они переиспользуются.
4. Обложки квадратные, с **центральным квадратным crop**, скругление `10%` размера. В исходнике без декоративной тени/рамки.
5. Карточка поворачивается по касательной к кругу. В верхней центральной точке располагается горизонтально; у краёв — под углом.
6. Масштаб растёт в верхней фокусной зоне, а прозрачность снижается к бокам. Перекрытия и клиппинг — часть визуального поведения.
7. Подпись является частью вращающейся карточки, центрирована под ней, до двух строк; лишние слова обрезаются с `...`.
8. Текст по умолчанию: `Inter Variable`, `Inter`, `sans-serif`; вес `500`, белый. Хост вправе задать `--arc-title-font-family`, `--arc-title-font-weight`, `--arc-title-color`. На светлом фоне белый текст может иметь недостаточный контраст: это **риск хоста**, не предложение переписать цвет по умолчанию.

### Spiral — структура

1. Прозрачный Canvas; центр композиции `(width/2, height/2)`.
2. Каждая карточка следует **1.5 оборотам спирали**; по мере движения растут размер, радиус и прозрачность.
3. Обложки квадратные, central crop + radius `10%`; поворот по касательной.
4. **В текущем исходнике нет видимых подписей** Spiral. Не добавлять их в After Effects как якобы исходное поведение.

### Обязательные состояния/форматы для дизайн-ревью

| Состояние | Цель |
|---|---|
| Arc / desktop, фаза `0.05` | Центр фокуса, средние углы, края, прозрачность |
| Arc / mobile, фаза `0.05` | Реальный размер `390×600`, границы и обрезка |
| Arc / desktop, фазы `0.00` / `0.25` / `0.50` / `0.75` | Тайминг, перестановка медиа и перекрытия |
| Spiral / desktop, фаза `0.05` | Масштаб/радиус/alpha/поворот |
| Spiral / mobile + reduced motion | Границы и статичная альтернатива |
| Arc / длинная подпись + другое изображение | Проверка двух строк, crop и пригодности шаблона |

Фазы в макетах — **условные нормированные состояния**, а не гарантированные кадры опубликованного сайта. Для настоящего референса фиксировать время `requestAnimationFrame`, DPR, файл медиа, браузер и source SHA.

## 3. Разработчик / Motion engineer

### Интерфейс и границы

Публичные функции: `mountArc(canvasId?, { items?: [{ src, title? }], maxDpr? })` и `mountSpiral(...)`. Возвращается `Promise<MountDisposer>`. Текущее состояние через `canvas.dataset.galleryState` (`loading` / `ready` / `error`). Это контракт существующей Canvas-библиотеки, **не** API для AE-шаблонов. Числа ниже — внутренние настройки renderer, **не добавлять их в публичный runtime API**.

Изоляция: новый AE-проект независим; не трогать `arc.ts`, `spiral.ts`, `.js` адаптеры, `gh-pages`, runtime lifecycle и CSS хоста. Интерфейс AE-шаблона: подмена `COVER_01…`, `TITLE_01…`, затем один `RENDER_MAIN`.

### Математика Arc (как в исходнике)

```ts
const phase = reducedMotion ? 0 : timeMs * 0.00005;
const minSide = Math.min(width, height);
const cx = width / 2, cy = height;
const radius = minSide * 0.7;
const baseSize = minSide * 0.17;
for (let i = 0; i < 10; i++) {
  const raw = i / 10 + phase;
  const t = raw % 1;
  const a = 2 * Math.PI * t;
  const x = cx + Math.cos(a) * radius;
  const y = cy + Math.sin(a) * radius;
  const topZone = Math.max(0, Math.cos(a - 1.5 * Math.PI));
  const focus = topZone ** 1.5;
  const size = baseSize * (0.25 + focus * 1.3);
  const edge = Math.abs(x - cx) / cx;
  const alpha = Math.min(1, Math.max(0, 1 - (edge - 0.68) * 6));
  const rotationRad = a + Math.PI / 2;
  const mediaIndex = (i + Math.floor(raw)) % items.length;
  // center crop → rounded rect radius size*.1; text up to 2 lines
}
```

Входное `time` у текущего renderer — timestamp `requestAnimationFrame` **в миллисекундах**. При нём период нормированной фазы Arc = `20,000 ms`, Spiral = `25,000 ms`. Само направление, отсечения и источник медиа сверять с кодом на зафиксированной ревизии, а не вручную «исправлять» под prettier-motion.

### Математика Spiral (как в исходнике)

```ts
const phase = reducedMotion ? 0 : timeMs * 0.00004;
const minSide = Math.min(width, height);
const maxSide = Math.max(width, height);
for (let index = 0; index < images.length; index++) {
  const t = (index / images.length + phase) % 1;
  const a = -t * 2 * Math.PI * 1.5 + Math.PI / 2;
  const size = minSide * 0.25 * (t * 1.5);
  const radius = size + t * maxSide * 0.4;
  const x = width / 2 + Math.cos(a) * radius;
  const y = height / 2 + Math.sin(a) * radius;
  const rotationRad = a + Math.PI / 2;
  const alpha = Math.min(1, t * 2);
}
```

### After Effects: скрипт и слои (предложение; пока не созданы)

```text
build-arc.jsx                        [генерация/обновление проекта в AE]
Arc.aep
  RENDER_MAIN                        [composition / transparent]
  ARC_SLOTS                          [precomp or separate layers]
    COVER_01 ... COVER_10            [replaceable images]
    TITLE_01 ... TITLE_10            [editable text]
  REFERENCE                           [optional, disabled on final render]

```

Spiral: аналогичные `COVER_XX`, но **без `TITLE_XX`** до изменения эталона. Для каждого адаптера должны быть документированы параметры, которые реально подменяются, и параметры, которые baked/pre-rendered.
