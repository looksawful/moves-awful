02 / Designer

Visual
anatomy.

Изображения по центру обрезаются до квадрата. Скругление составляет 10% размера карточки. В Arc подпись вращается вместе с карточкой, центрирована и ограничена двумя строками.

SurfaceCanvas прозрачный. Тёмный фон здесь только для демонстрации, а не часть компонента.
MotionПоложение, масштаб и прозрачность вычисляются от одной фазы. Без дополнительных пружин, теней и 3D.
TypographyInter Variable / Inter, weight 500, white по умолчанию; цвет, гарнитура и вес могут задаваться хостом.
BreakpointsАлгоритм один; геометрия пересчитывается по размеру контейнера. Проверять отсечения на узких кадрах.
03 / Engineering

Small
interface.

Публичный контракт сайта менять не нужно. Отдельный результат задачи: шаблон AE с заменяемыми медиа/текстом и статичный PSD ключевого кадра.

Public APImountArc(id, { items?: [{src,title?}], maxDpr? }); аналогично mountSpiral; результат = disposer.
ArcВерхняя фокусная зона, edge fade и rotation повторяют формулы arc.ts. 10 слотов, не 10 изображений.
SpiralПеремещается весь список изображений; непрерывное увеличение масштаба и alpha, без подписей в текущем рендере.
ValidationСначала source SHA + эталон, затем пилот Arc, сравнение кадров/движения, только после этого Spiral.
04 / Delivery

One decision, three handoffs.

D / VISUAL

Designer

Проверяет угол, масштаб, обтравку, композицию, перекрытия, контраст подписей, мобильный кадр и безопасный статичный вариант reduced motion.

E / IMPLEMENTATION

Developer

Делает один .aep для Arc. Изображения и подписи заменяются независимо; сохранение и повторный рендер проверяются на Titan. PSD создаётся после принятия Arc.

P / DECISION

Product

Принимает пилот по визуальному совпадению, заменяемости, открываемости и документированным отличиям. Spiral начинается после прохождения контрольного этапа Arc.
