# Agent skill routing

Project-local behavior rules live in `AGENTS.md` and `.agents/skills/`.

For generic specialist guidance, use the reviewed vendor registry in `skills/vendor/registry.yaml` and install only the skill required by the task. Do not copy the full `looksawful.ru` skill tree into this repository.

Current vendor candidates:

- animation/runtime performance: `MengTo/Skills:optimize-web-animations`;
- accessibility: `addyosmani/web-quality-skills:accessibility`;
- strict TypeScript work: `lobehub/lobehub:typescript`.

See `skills/vendor/README.md` and `skills/vendor/pins.md` for installation policy and reviewed revisions.
